WanderWay — Assignment 5

HOW TO RUN
1. Extract this ZIP folder.
2. Open Travel_Assignment_4/index.html in a modern browser.
3. Internet access is needed for the Bootstrap CDN; local images, CSS and JavaScript are included.

FEATURES IMPLEMENTED
- DOM selection and dynamic text/style changes.
- Day/night theme switch and background color cycling.
- Readable FAQ accordion and subscription popup.
- Current date/time updated every second.
- Destination Finder uses objects, arrays, filter(), event listeners and switch.
- Keyboard navigation of the main navigation using arrow keys.
- Travel chime generated with Web Audio API.
- CSS animation for changing destination suggestions.
- HTML, CSS and JavaScript are separated.
